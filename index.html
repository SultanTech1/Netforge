Networking Fundamentals

أساسيات الشبكات

What is Computer Networking?ما هي شبكات الحاسوب؟

A computer network is a collection of two or more computing devices connected to share resources and communicate. Networks range from two laptops connected by a cable to the global Internet.

شبكة الحاسوب هي مجموعة من جهازين أو أكثر متصلة لمشاركة الموارد والتواصل. تتراوح من جهازي حاسوب محمولين إلى الإنترنت العالمي.

Key Metrics

المقاييس الرئيسية

  • Bandwidth: max theoretical data rate.
  • عرض النطاق: أقصى معدل بيانات نظري.
  • Throughput: actual measured rate.
  • الإنتاجية: المعدل الفعلي المقاس.
  • Latency: packet travel time (ms).
  • الكمون: زمن انتقال الحزمة (ms).
  • Jitter: latency variation.
  • التذبذب: تباين الكمون.
  • Packet Loss: % of lost packets.
  • فقدان الحزم: نسبة الحزم المفقودة.

Network Devices

أجهزة الشبكات

Router (الموجّه)الموجّه (Router)

A router is a Layer 3 device that forwards packets between different IP networks based on its routing table.

الموجّه جهاز من الطبقة الثالثة يعيد توجيه الحزم بين شبكات IP بناءً على جدول التوجيه.

Router> enable
Router# configure terminal
Router(config)# hostname R1
R1(config)# interface Gi0/0
R1(config-if)# ip address 192.168.1.1 255.255.255.0
R1(config-if)# no shutdown
R1(config)# ip route 0.0.0.0 0.0.0.0 10.0.0.2

Switch (المبدّل)المبدّل (Switch)

A switch is a Layer 2 device that forwards frames based on MAC addresses.

المبدّل جهاز من الطبقة الثانية يعيد توجيه الإطارات بناءً على عناوين MAC.

Switch# configure terminal
Switch(config)# vlan 10
Switch(config-vlan)# name Sales
Switch(config)# interface Fa0/1
Switch(config-if)# switchport mode access
Switch(config-if)# switchport access vlan 10

IP Addressing

عناوين IP

IPv4 & IPv6

An IP address is a logical address assigned to a device. It has a network portion and a host portion separated by a subnet mask.

عنوان IP هو عنوان منطقي يُعيّن لجهاز، يتكون من جزء الشبكة وجزء المضيف يفصل بينهما قناع الشبكة.

Enterprise Network Challenge

تحدي الشبكة المؤسسية

Design a complete enterprise network step by step.

صمم شبكة مؤسسية كاملة خطوة بخطوة.

Stage 1: Requirements

A company has 4 departments: Administration (20 hosts), IT (15), Users (50), Servers (10). Design VLANs and IP addressing.

شركة لديها 4 أقسام: الإدارة (20 مضيفًا)، تقنية المعلومات (15)، المستخدمون (50)، الخوادم (10). صمم VLANs وعنونة IP.

Stage 2: Topology

Sketch: Internet → Firewall → Router → Core Switch → Access Switches → PCs/Servers.

ارسم: الإنترنت → جدار ناري → موجّه → مبدّل أساسي → مبدلات وصول → أجهزة PC/خوادم.

Stage 3: IP Addressing (VLSM)

Suggested plan from 192.168.0.0/22:

خطة مقترحة من 192.168.0.0/22:

VLANVLANNameSubnetGateway
10Admin192.168.0.0/27192.168.0.1
20IT192.168.0.32/27192.168.0.33
30Users192.168.0.64/26192.168.0.65
40Servers192.168.0.128/28192.168.0.129
Stage 4: VLANs
SW(config)# vlan 10
SW(config-vlan)# name Admin
SW(config)# vlan 20
SW(config-vlan)# name IT
Stage 5: Routing

Configure inter‑VLAN routing on the L3 switch or router, then enable OSPF to reach the WAN.

قم بإعداد التوجيه بين VLAN على مبدّل L3 أو الموجّه، ثم فعّل OSPF للوصول إلى WAN.

Stage 6: Services

Configure DHCP pools for VLAN 10/20/30, DNS server at 192.168.0.130, NTP at 192.168.0.131.

قم بإعداد DHCP لـ VLAN 10/20/30، خادم DNS على 192.168.0.130، NTP على 192.168.0.131.

Stage 7: Security

Configure ACLs to block Users VLAN from Servers VLAN, enable port security, and set up SSH on devices.

قم بإعداد ACL لمنع VLAN المستخدمين من الوصول إلى VLAN الخوادم، وفعّل أمن المنافذ، وقم بإعداد SSH على الأجهزة.

Stage 8: Testing & Verification
  • Ping gateway from each VLAN.
  • اعمل ping للبوابة من كل VLAN.
  • Verify DHCP assignments with ipconfig /all.
  • تحقق من تعيينات DHCP باستخدام ipconfig /all.
  • Test ACL blocking with ping across VLANs.
  • اختبر حظر ACL باستخدام ping بين VLANs.
  • Verify routing table shows all networks.
  • تحقق من أن جدول التوجيه يعرض جميع الشبكات.
